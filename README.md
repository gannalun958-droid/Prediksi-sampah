# Prediksi-sampah
Project ini membuat prediksi sampah rumah tangga setiap Minggu 
tujuan proyek untuk menghitung jumlah sampah perminggu 
cara menjalankan menggunakan python atau web google Collab
hyper parameter yang di coba dan hasil terbaik 
waktu pelatihan light gbm : 40,10 DETIK metrik mse LIGHTGBM:3.8405, dan R2 score LightGBM: 87.63%
keterbatasan sebatas rumah tangga dalam RT RW dan lingkungannya
